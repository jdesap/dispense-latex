# Nuove materie, inclusa Algebra

Creare la cartella della materia direttamente nella raccolta, allo stesso
livello di `analisi 1` e `geometria 1`. Copiare qui il file `.latexmkrc`
di questo modello, accanto al nuovo `main.tex`.

Il documento deve caricare `hyperref` e `bookmark` e organizzare i temi
con capitoli numerati (`\chapter{...}`). Conservare lo stile concordato
per titolo, autore, docente, fonti e registri.

La normale compilazione produce automaticamente il volume completo in
`build/main.pdf` e i capitoli separati in `build/capitoli/`. Non serve
preparare una lista manuale di capitoli né una compilazione per ogni file.
Il modello configura la compilazione; il contenuto di Algebra verrà
preparato quando l'autore consegnerà le fonti.
